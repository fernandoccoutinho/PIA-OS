# Contribuindo — PIA-OS Backend

O guia de contribuição vive em
[`CONTRIBUTING.md`](../../CONTRIBUTING.md), na raiz do repositório — é
onde ferramentas como GitHub/GitLab esperam encontrá-lo (renderizado
automaticamente ao abrir um Pull Request). Este arquivo não o duplica.

Cobre: convenções de nomenclatura, estrutura de camadas, regra de acesso
a dados, regra de logging, regra de erros, regra de segurança, regra de
documentação, regra de testes, regra de deploy, configuração.

Ver também [`docs/development/coding_standards.md`](coding_standards.md)
e [`docs/development/workflow.md`](workflow.md) para o que
`CONTRIBUTING.md` não cobre em detalhe.
