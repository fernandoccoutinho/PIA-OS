# Prompts dos Módulos — PIA-OS Backend

## Nota importante sobre disponibilidade

Esta sessão de trabalho começou com um **resumo já compactado** dos
Módulos 2.1–2.7 (uma transcrição completa anterior, referenciada mas não
recarregada integralmente) — o texto literal dos prompts originais
desses módulos não está disponível neste contexto. Os arquivos
`prompt-2.1.md` a `prompt-2.7.md` refletem isso honestamente: descrevem
o que foi implementado (a partir do resumo real disponível), não
reproduzem um texto de prompt que eu não tenho.

Os prompts de **2.8 a 2.13 estão reproduzidos com fidelidade ao texto
original** recebido nesta conversa (condensados nos pontos-chave —
objetivo, escopo, estrutura, critérios de aceitação — para caber num
documento de navegação; o texto integral de cada um está preservado no
histórico da conversa que gerou este projeto, não neste repositório).

## Por que isso importa

Um Build Kit que fabricasse prompts para preencher a lista seria pior
que um Build Kit incompleto e honesto sobre a lacuna — a rastreabilidade
só tem valor se for verdadeira.
