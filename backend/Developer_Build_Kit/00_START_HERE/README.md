## O que este Build Kit é (e não é)

É um mapa de navegação sobre documentação e código que já existem —
não duplica conteúdo. Cada arquivo aqui dentro ou é um índice, ou é um
relatório gerado nesta etapa (Módulo 2.13) que não existia em lugar
nenhum antes.
